# 规则逆向解析后端接口需求

本文档是前端实现闭环所需的后端能力清单，不是正式接口文档。字段命名、校验细节和错误码可由后端最终定稿，但需要覆盖以下输入输出。

## 任务创建接口

- 功能：创建逆向解析任务，接收任务名称、可选合同类型、可选审核视角、可选规则版本，以及 1-5 组修改前/修改后合同文件。
- 输入：multipart form-data；任务元信息包括 `task_name`、`contract_type`、`review_role`、`rule_version_id`；合同组包括 `pair_name`、`before_file`、`after_file`。
- 输出：`task_id`、任务状态、可用于跳转进度页的任务摘要。
- 说明：后端负责解析合同文件正文，并调用逆向解析工作流；前端不抽取合同正文。

## 任务列表接口

- 功能：分页查询逆向解析任务，支持状态、合同类型、创建时间范围筛选。
- 输入：`status`、`contract_type`、`created_from`、`created_to`、`skip`、`limit`。
- 输出：任务列表、总数、分页信息；列表项需包含任务名、状态、进度、合同组数、候选规则数、纳入/忽略/待处理数量、创建/更新时间。

## 任务详情/进度接口

- 功能：返回任务当前状态、整体进度、步骤状态、每组合同执行状态、统计、失败信息。
- 输入：`task_id`。
- 输出：任务详情；状态用于前端跳转到进度页、候选规则确认页、失败页或成功页。

## 候选规则接口

- 功能：返回某任务生成的候选规则和来源证据。
- 输入：`task_id`。
- 输出：候选规则列表；字段需覆盖 `contract_type`、`review_role`、`review_module`、`risk_name`、`check_point`、`trigger_condition`、`default_risk_level`、`suggestion_template`、`example_clause`、`traces`，并额外包含候选规则 ID、决策状态、置信度、来源合同组。

## 候选规则决策接口

- 功能：单条或批量设置候选规则为纳入、忽略、待处理。
- 输入：候选规则 ID 或 ID 列表、`decision`。
- 输出：更新后的候选规则或候选规则列表，同时更新任务统计。

## 确认入库接口

- 功能：把已纳入的候选规则写入正式规则库。
- 输入：`task_id` 和纳入候选规则 ID 列表；后端也可以按任务内 `included` 状态读取。
- 输出：入库成功统计、生成的正式规则列表、忽略规则列表。
- 说明：`id`、`version_id`、`rule_code`、`enabled`、`created_at`、`updated_at` 由后端生成。

## 重试接口

- 功能：失败任务重新发起解析。
- 输入：`task_id`。
- 输出：新的任务状态或任务详情。

## 导出接口

- 功能：导出本次候选规则、纳入规则、忽略规则。
- 输入：`task_id`。
- 输出：Excel 或 CSV 文件流。
